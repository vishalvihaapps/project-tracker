# Example Skill

Replace this body with the procedure Claude should follow when this skill runs.

A skill is a folder under `.claude/skills/` containing a `SKILL.md`. The folder
name and the `name` field should match. Supporting files (scripts, templates,
reference docs) can live alongside this file and be referenced by relative path.

The `description` is what Claude reads to decide whether to invoke the skill —
make it specific about both the capability and the trigger conditions.
