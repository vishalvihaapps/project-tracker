name: deploy-to-vercel
description: Deploy the application to production
---

Deploy the application:
1. Pull the latest changes from main
2. Install dependencies and run tests
3. Push changes to github this will auto deploy to vercel
4. Verify the deployment on vercel dashboard
5. If there are any issues, check the logs on vercel and fix them accordingly
6. Once the deployment is successful, share the live URL with the team and stakeholders
7. Monitor the application for any issues and address them promptly
8. Document the deployment process and any issues encountered for future reference
9. Set up alerts for any critical issues in production to ensure quick response times
10. Schedule regular maintenance and updates to keep the application running smoothly and securely.
